# UnarVault 🌐

UnarVault is a personal family memories vault designed for storing and viewing photos, videos, and trips. It serves as a secure, private media archive for family relatives to preserve and share cherished moments.

Focusing on simplicity, performance, and a modern, high-quality user experience, the website runs entirely client-side without complex backend server dependencies.

---

## Features

- **Hero Slide**: A responsive, automated top slide displaying highlighted moments with smooth transitions.
- **Family Albums Grid**: Clean, modern cards featuring interactive hover effects that display collections of memories.
- **Album Gallery Page**: A sleek grid and masonry layout supporting image and video thumbnails.
- **Lightbox / Modal Viewer**: Full-screen preview of images and videos with responsive navigation controls.
- **Centralized Data**: A clean, single-source-of-truth JSON configuration for easy album organization.
- **Future Integration Ready**: Structured to seamlessly scale and support cloud media hosting, including Google Drive folders, Cloudinary optimizations, and YouTube embedding.
